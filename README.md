# ADX 流量分组管理还原版

根据测试后台页面还原的可交互前端原型。项目使用 React + vinext，数据保存在浏览器本地，不会写入原测试后台。

## 已还原功能

- 广告场景、平台筛选和分组切换
- 新增、编辑、复制分组
- 动态增删分组规则
- 分组启停、A/B 组和流量占比调整
- A/B 测试数据查看
- 新增、编辑 DSP 来源和多 PID
- DSP 启停、底价内联编辑、未启用来源折叠
- 侧边栏折叠与响应式布局
- 浏览器本地持久化

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址（默认 `http://localhost:3000/`）。

## 验证

```bash
npm run build
npm test
```
