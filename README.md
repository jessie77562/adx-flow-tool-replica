# ADX 流量分组管理还原版

根据测试后台页面还原的可交互前端原型。项目使用 React + vinext，数据保存在浏览器本地，不会写入原测试后台。

## 已还原功能

- 广告场景、平台筛选和分组切换
- 新增、编辑、复制分组
- 分组管理弹窗：拖拽排序、P1/P2 优先级、批量启停与单独开关，确认后统一保存
- 默认分组固定置底、始终启用且不可停用
- 已启用分组展示“生效中”标签，默认仅展示生效中的分组
- 首次进入、切换场景或平台时，默认定位到优先级最高的生效分组
- 动态增删分组规则
- 分组启停、A/B 组和流量占比调整
- A/B 测试数据查看
- 新增、编辑 DSP 来源和多 PID
- DSP 启停、底价内联编辑、未启用来源折叠
- PID 多选与批量停用、启用、设置价格
- 批量价格校验：必填、有效正数、大于 0、不得超过 9999 元上限
- 侧边栏折叠与响应式布局
- 浏览器本地持久化

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址（默认 `http://localhost:3000/`）。

## 验证

```bash
npm run build
npm test
```

这是独立演示版：使用仿真数据和本地状态，未连接原站接口，所有提交只影响当前浏览器里的演示数据。
