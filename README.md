# ADX 广告位策略管理优化版

根据测试后台页面还原的可交互前端原型。项目使用 React + vinext，数据保存在浏览器本地，不会写入原测试后台。

## 本次优化

- 配置层级由“广告场景 → 平台”下沉为“广告场景 → 平台 → 最小广告位”
- 每条策略固定归属一个广告位，不能跨广告位共享流量
- 同广告位策略按唯一优先级从高到低判断
- 首条命中后立即停止，单用户在一次广告请求中最多命中一条策略
- 未命中时继续判断，最后由无条件兜底策略承接
- 内置命中测试，可查看“未命中继续 / 命中即停止”的执行轨迹
- 新增、编辑、复制策略以及动态增删定向规则
- 策略内多条规则使用 AND 语义
- 策略启停、A/B 组和流量占比调整
- A/B 测试数据查看
- 新增、编辑 DSP 来源和多 PID
- DSP 启停、底价内联编辑、未启用来源折叠
- 侧边栏折叠与响应式布局
- 浏览器本地持久化

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址（默认 `http://localhost:3000/`）。

## 验证

```bash
npm run build
npm test
```

## 说明

这是独立演示版：使用仿真数据和本地状态，未连接原站接口，所有提交只影响当前浏览器里的演示数据。互斥规则由 `app/strategy-engine.ts` 实现，并由自动化测试覆盖首条命中终止、跨广告位隔离、禁用策略跳过、兜底与优先级约束。
